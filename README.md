## Featured Project

### Toronto Condo Rental Analysis

[View the dedicated repository](https://github.com/BlazingTheTrail/toronto-condo-rental-analysis)

An end-to-end Python project that collects rendered Toronto condo rental
listings, validates and cleans the data, and produces a reproducible market
analysis.

Highlights:

- Chromium-based collection with DrissionPage
- Defensive parsing, deduplication, and data-quality controls
- 18 automated tests
- Controlled 10-page validation with 492 unique listings
- 490 analysis-ready records
- Reproducible Jupyter Notebook and versioned charts

Technology: Python, pandas, DrissionPage, Matplotlib, and `unittest`.
